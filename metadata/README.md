# Metadata (ADF control database)

| File | Purpose |
|---|---|
| `adf_control_db.sql` | T-SQL DDL + stored procedures for Azure SQL `ctl` schema (source systems, objects, watermarks, backfill partitions, run log, legacy recon queries) |
| `source_object_seed.csv` | One row per extracted object — **onboarding a table = one row here + its RAW DDL/pipe in Snowflake** |
| `recon_legacy_queries.sql` | Oracle-side aggregate/hash queries run against the legacy EDW during parallel run |

`src/tools/adf_validate.py` cross-checks that every `target_path` here has a
matching Snowpipe prefix in `snowflake/03_raw/02_pipes.sql`, so a typo can't
silently land files that no pipe ever loads.

Backfill partitions are generated by `python -m src.tools.backfill_plan`
(month × id-range split when a month exceeds 50 M rows) and bulk-inserted into
`ctl.backfill_partition`.
